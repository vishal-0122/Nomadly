# 🏝️ Nomadly - AI-Powered Smart Travel Planner

## 📌 Overview
Nomadly is an AI-powered smart travel planner designed to help travelers optimize their trips by recommending personalized destinations based on budget, trip duration, and past travel history. This repository contains small-scale implementations for testing the feasibility of the idea using machine learning models.

## 🗃️ Dataset Information
- The dataset used in this project (`travel_data & travel_preferences.csv`) is **self-generated** for the purpose of testing the AI model.
- It contains synthetic travel preference data such as budget, trip duration, and past trips.
- **Note:** This dataset is **not sourced from any official provider** and is only used for prototype testing.

## 🚀 ML Implementation
- The repository contains basic machine learning implementations for testing the viability of AI-powered travel recommendations.
- **Tech stack used:**
  - `Pandas` for data preprocessing
  - `Seaborn & Matplotlib` for data visualization
  - `Scikit-learn` for model training and evaluation
  - `K-Nearest Neighbors (KNN)` and `Random Forest` models tested
- **Purpose:** The implementation is only for **small-scale validation** and does not represent a production-ready system.
